📖 How to Use

Controls

  • Click canvas — Lock cursor for mouse look (or drag with mouse)
  • WASD — Move horizontally (Minecraft style)
  • Space — Fly up
  • Shift / C — Fly down
  • Ctrl — Sprint (3× speed)
  • Esc — Release cursor / close panels

Entering Equations

Type LaTeX in the input bar. The equation should be in the form LHS = RHS. If no = is given, it's treated as expr = 0.

Examples:

  • x^2+y^2+z^2=1 — Sphere
  • \sin(x)+\sin(y)+\sin(z)=0 — Gyroid
  • \cos(x)\cos(y)\cos(z)=0.3 — Lattice
  • \frac{x^2}{4}+y^2+z^2=1 — Ellipsoid

Supported Functions

\sin, \cos, \tan, \sec, \csc, \cot, \arcsin, \arccos, \arctan, \sinh, \cosh, \tanh, \ln, \log, \log_{n}, \exp, \sqrt, \abs, \floor, \ceil, \gcd, \min, \max, \mod, \sign

Desmos Semantics

  • Functions that take integers (like \gcd) use floor on their arguments
  • Undefined values (e.g., \log(-1)) show the skybox
  • \log is base 10; \ln is natural log
  • Use \log_{2}(x) for log base 2

Performance Tips

  • Lower Resolution for faster rendering
  • Increase Step Size to render faster (may miss thin surfaces)
  • Decrease Max Distance to render only nearby geometry
  • Decrease Max Steps for better framerate
